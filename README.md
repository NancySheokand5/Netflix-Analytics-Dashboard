 Netflix Movies and TV Shows Data Analysis
This project explores the Netflix Movies and TV Shows dataset, analyzing trends in content type, release years, genres, ratings, and countries of production using Python, Pandas, and Matplotlib.
 About the Dataset
The dataset contains information about Netflix's catalog, including:

Title, type (Movie/TV Show), and director
Cast, country, and date added to Netflix
Release year, rating, and duration

 Tools & Libraries Used

Pandas – for data cleaning, manipulation, and exploratory data analysis (EDA)
Matplotlib – for creating visualizations such as bar charts, line graphs, and pie charts to represent trends in the data

 Key Analysis & Visualizations

Distribution of Movies vs TV Shows on Netflix
Number of titles released per year
Top countries producing Netflix content
Most common genres and ratings
Trend of content added to Netflix over the years
